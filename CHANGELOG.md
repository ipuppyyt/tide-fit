# Changelog

All notable changes are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/).

## [0.1.0] - 2026-11-16
First public release.

### Added
- Onboarding, profile, and transparent calorie and macro estimates (saved only if accepted).
- Nutrition: food log, recipes, hydration, daily targets with append-only history.
- Training: exercise library, routines, live workouts with rest timer, history and analytics.
- Body: weight, measurements, sleep, recovery and supplements.
- ChatGPT coaching: JSON export and import with validation, preview, duplicate detection and rollback.
- Health Connect two-way sync.
- Streaks with a home pill, details screen, reminders and milestone notifications.
- Home screen widgets: Today, Calories, Water, Workout and Streak.
- Backup and restore, colour palettes, light and dark themes.
